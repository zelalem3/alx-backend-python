# ALX Backend Python

Backend Python exercises completed as part of the ALX curriculum. The projects explore type annotations, asynchronous programming, and testing.

## Topics

- Python type annotations and variable annotations
- Async functions and concurrent execution
- Asynchronous comprehensions and generators
- Unit and integration testing

## Repository structure

| Directory | Topic |
| --- | --- |
| `0x00-python_variable_annotations` | Type annotations |
| `0x01-python_async_function` | Async functions |
| `0x02-python_async_comprehension` | Async comprehensions |
| `0x03-Unittests_and_integration_tests` | Testing |

Each project directory contains its own exercises and supporting files.

## Requirements

- Python 3
- Project-specific dependencies, if any

Check each directory for its task files and instructions. If a dependency file is present, install from it in a virtual environment.

## Running tests

Test commands can differ by project. Check the files in the project directory for the relevant test instructions.

## Note

This repository contains coursework and practice code. It is intended for learning and may not be production-ready.
